# 开发工具

[返回首页](../README.md)

统一工具入口为 **Lcc框架 → 工具箱**。配置生成步骤见 [快速开始](快速开始.md)，资源构建见 [热更新与构建](热更新与构建.md)。以下工具按当前源码整理，未实际执行导出或生成操作。

## Luban 数据表

[DataTables](../DataTables) 存放数据表、Luban 配置与导出脚本。Windows 入口为 [gen.bat](../DataTables/gen.bat)，工具依赖 .NET 8 运行时。

执行前，在 `DataTables` 目录核对脚本中的相对路径和输出目录：

| 输出 | 当前脚本路径 |
| --- | --- |
| C# 数据类 | `Assets/Hotfix/GameLogic/Package/LubanConfig/Gen` |
| JSON 数据 | `Assets/Res/LubanConfig` |

当前脚本的数据输出路径需要与实际 YooAsset 收集位置核对，不能仅凭导出成功判断运行时可以加载。运行时 [ConfigManager.cs](../Assets/Hotfix/GameLogic/Package/Config/ConfigManager.cs) 通过 `luban` 标签收集配置并创建 `Tables`；数据地址需要与生成代码读取的名称匹配。

## Protobuf 协议

1. 在 [Message/proto](../Message/proto) 维护 `.proto` 文件。
2. 打开 **Lcc框架 → 工具箱 → PB生成工具**，执行 **生成协议**，中间输出为 `Message/protoCS`。
3. 核对输出后执行 **导入**，将消息代码同步至 `Assets/Hotfix/GameLogic/Message`。

导入会同步增删生成文件，协议源文件应作为维护入口。具体生成和同步行为见 [PBGenEditorWindow.cs](../Assets/Editor/Editor/OdinEditorWindow/PBGenEditorWindow.cs)。

## 调试与内容辅助

| 工具 | 入口 |
| --- | --- |
| 重启游戏 | 工具箱 → 重启游戏（F5） |
| 退出账号 | 工具箱 → 退出账号（F6） |
| 引用池查看器 | Lcc框架 → 工具箱 → 引用池查看器 |
| UI 工具 | Lcc框架 → 工具箱 → UI工具 |
| 本地化文本 | GameObject → UI → 本地化文本；文本组件右键菜单提供转换入口 |
| 多语言检查 | 工具箱 → 多语言Key检查工具 |
| 音频库编辑 | 工具箱 → 音频库编辑器 |
| 模型挂点 | 选中资源后，Assets → 生成模型挂点 |

重启游戏与退出账号入口调用运行中的热更业务方法，应在游戏运行时使用。更多目录和服务职责见 [架构说明](架构说明.md)。
